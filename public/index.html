Murmure : la messagerie privée chiffrée de bout en bout

Murmure est une messagerie web qui permet à deux personnes d'échanger des messages, des images et des GIFs à travers un canal chiffré de bout en bout. Aucun compte, aucune adresse email, aucune donnée personnelle : seul un code secret partagé sert à dériver la clé cryptographique. Le serveur ne voit que du texte chiffré qu'il ne peut techniquement pas déchiffrer.

Une cryptographie standard, auditable

Les messages sont chiffrés dans ton navigateur via l'API WebCrypto avec l'algorithme AES-256 en mode GCM, considéré comme l'état de l'art en chiffrement symétrique authentifié. La clé est dérivée du code secret par PBKDF2-SHA256 avec 250 000 itérations, ce qui ralentit considérablement toute tentative d'attaque par force brute. Une empreinte cryptographique affichée en haut du salon permet de vérifier visuellement que les deux côtés utilisent bien la même clé.

Pourquoi choisir Murmure ?

  • Zéro inscription : pas de compte, pas d'email, pas de numéro de téléphone.
  • Zéro publicité : aucun script de tracking, aucun analytics commercial.
  • Code source minimal : dépendances réduites, comportement explicite.
  • Réactions emoji illimitées : plusieurs réactions par utilisateur sur un même message, parmi des centaines d'emojis.
  • Médias chiffrés : les images envoyées dans le chat sont chiffrées comme les messages texte.
  • Bibliothèque GIF intégrée : recherche et envoi de GIFs animés via Giphy.
  • Aperçus de liens : cartes Open Graph rendues côté serveur pour préserver ta vie privée.
  • Notifications d'appel : ton interlocuteur peut « sonner » même si l'onglet est fermé.
  • Protection anti-robot : Cloudflare Turnstile + rate-limit par IP côté serveur.
  • Rétention courte : l'historique chiffré est purgé après 6 heures.

Pour quel usage ?

Murmure est pensé pour les conversations privées entre deux personnes : partage de codes d'accès, discussions sensibles, échange d'informations confidentielles, ou simplement par souci de discrétion vis-à-vis des messageries grand public. Ce n'est pas un remplacement à Signal pour une utilisation quotidienne longue durée, mais un outil léger, sans friction, accessible depuis n'importe quel navigateur en quelques secondes.

Questions fréquentes

Tout ce qu'il faut savoir avant de commencer une conversation chiffrée sur Murmure.

Le serveur peut-il lire mes messages ?
Non. Le chiffrement et le déchiffrement se font intégralement dans ton navigateur. Le serveur reçoit uniquement le couple { iv, ct } chiffré et n'a aucun accès à la clé.
Que se passe-t-il si je perds le code ?
Sans le code secret, les messages chiffrés deviennent illisibles à jamais. C'est le prix du chiffrement de bout en bout : il n'existe aucun mécanisme de récupération et c'est exactement ce qui garantit ta confidentialité.
Combien de temps les messages sont-ils conservés ?
L'historique chiffré reste 6 heures côté serveur puis est automatiquement purgé. Même pendant cette fenêtre, il reste illisible sans le code.
Comment partager le code en toute sécurité ?
Utilise un canal de confiance distinct : en personne, par appel vocal, ou via une application déjà chiffrée comme Signal. Évite SMS, email non chiffré et réseaux sociaux.
Le site fonctionne-t-il sur mobile ?
Oui. L'interface est responsive et s'installe en tant qu'application web progressive (PWA) via le manifeste fourni. Notifications push supportées sur navigateurs compatibles.
Faut-il créer un compte ?
Non. Aucune inscription, aucun email, aucun numéro de téléphone. Tu choisis un pseudo temporaire optionnel et un code partagé avec ton interlocuteur.
